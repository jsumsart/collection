African Art Record

Figural Slingshot Handle with Twin Figures

West African peoples, possibly Baule or Lobi-region, attribution uncertain

Object Number JA-2022-39
Date Late 19th–early 20th century
Culture / Community West African peoples, possibly Baule or Lobi-region, attribution uncertain
Object Type Figural slingshot / catapult handle

This carved wooden slingshot or catapult handle has a fork formed by two elongated human figures standing back-to-back or side by side on a shared handle. The object has a worn surface, simplified limbs, prominent ears, and crest-like head forms. As a West African figural slingshot, it transforms a handheld implement into a sculptural image of paired bodies.
